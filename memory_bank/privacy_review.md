# V0.1.0 隐私与网络审查

## 本地数据

食品名称、库存数量、生产日期、到期日期、备注、分类、位置和本地图片只写入应用沙箱中的 SQLite、SharedPreferences 或 `food_images` 托管目录。清除本地数据会取消待处理通知，清空业务表和条码缓存，删除用户分类、用户位置、设置与托管图片，再恢复系统默认分类和位置。

## 允许的网络范围

- Android 仅声明通用 `INTERNET` 权限；iOS 不配置任意 HTTP 例外；
- 远程商品查询基地址必须由 `AppConfig` 提供并使用 HTTPS；
- 扫码请求只允许发送规范化条形码、`cc=cn`、`lc=zh`、`tags_lc=zh` 和最小响应字段集合；
- 可下载 Open Food Facts 返回的 HTTPS 商品图片；
- 禁止发送本地食品库存、数量、生产日期、到期日期、备注和本地文件路径。

步骤 78—85 接入远程查询后，应在 Android 调试构建中抓包复核请求主机、查询参数和请求体；当前步骤 75 执行时应用尚无业务网络请求。

## 日志

应用日志只允许输出内部 snake_case 事件名和异常类型，不输出异常消息、堆栈、完整业务对象、备注、远程完整响应或绝对文件路径。生产环境关闭应用日志。
