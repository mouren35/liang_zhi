# V0.1.0 隐私与网络审查

## 本地数据

食品名称、库存数量、生产日期、到期日期、备注、分类、位置和本地图片只写入应用沙箱中的 SQLite、SharedPreferences 或 `food_images` 托管目录。清除本地数据会取消待处理通知，清空业务表和条码缓存，删除用户分类、用户位置、设置与托管图片，再恢复系统默认分类和位置。

## 允许的网络范围

- Android 声明 `INTERNET`、扫码所需 `CAMERA`、Android 13+ 本地提醒所需 `POST_NOTIFICATIONS` 和重启恢复本地调度所需 `RECEIVE_BOOT_COMPLETED`；不声明存储、位置、联系人、麦克风、账号或精确闹钟权限；iOS 不配置任意 HTTP 例外；
- 远程商品查询基地址必须由 `AppConfig` 提供并使用 HTTPS；
- 扫码请求只允许发送规范化条形码、`cc=cn`、`lc=zh`、`tags_lc=zh` 和最小响应字段集合；
- 可下载 Open Food Facts 返回的 HTTPS 商品图片；
- 禁止发送本地食品库存、数量、生产日期、到期日期、备注和本地文件路径。

步骤 78—85 已通过注入 `MockClient` 精确捕获生产 Repository 生成的请求，确认方法为 GET、路径为固定 v2 商品接口、无请求体，查询参数和字段集合符合上述白名单。Android 调试环境未配置 HTTPS 代理，因此发布前仍需在可用代理环境复核真实远程流量。

## 日志

应用日志只允许输出内部 snake_case 事件名和异常类型，不输出异常消息、堆栈、完整业务对象、备注、远程完整响应或绝对文件路径。生产环境关闭应用日志。

平台与性能集成测试中的 `print` 只输出固定测试阶段名、权限枚举和毫秒指标，不包含食品内容、条码、文件路径或远程响应；这些测试入口不打入正式应用入口。
