# 粮知 V0.1.0 回归清单

每次发布候选版本在 Android 设备/模拟器执行；iOS 项在可用外部环境执行并记录设备与结果。

- [x] 冷启动在 2 秒内进入首页，无白屏或未捕获错误；
- [x] 五项底部导航顺序、文案、选中状态和分支状态保持正确；
- [x] 空库存可从首页/全部食物进入手动添加；
- [x] 名称、正数量、单位和两种到期方式校验正确；
- [x] 新增后出现轻量成功反馈，列表自动刷新且重启后数据保留；
- [x] 列表长名称、今天到期、临期和已过期样式无溢出；
- [x] 详情与原列表数据一致，返回后保留列表位置；
- [x] 扫码命中、未命中、离线、超时、429/5xx 和权限拒绝均可安全回退；
- [x] 四类通知设置、聚合、点击跳转、时区重排和取消正确；
- [x] 清除数据取消不执行，确认后食品/缓存/设置/图片/通知清除且默认项恢复；
- [x] 数据库、网络、相机或通知错误只展示友好信息；
- [x] 320×568 小屏与 200% 文本缩放下关键操作可访问；
- [x] Open Food Facts 来源、ODbL、本地存储与联网范围说明可见；
- [x] `dart format --output=none --set-exit-if-changed .`、`flutter analyze`、`flutter test` 通过；
- [x] Android 调试 APK 与发布候选构建通过；
- [ ] macOS CI 的 `flutter build ios --no-codesign` 通过；
- [x] iOS 真机、签名和 TestFlight 结果已记录；无环境时明确标为外部阻塞。

Android API 37 Release 稳定冷启动实测 1700 ms、1535 ms。adb 替换安装后的首次启动为 8368 ms，受模拟器安装后包优化影响，已在验收记录中单列，不作为稳定冷启动结果。macOS CI 与 iOS 真机项保持外部未执行，不报告为通过。
