# 粮知 V0.1.0 回归清单

每次发布候选版本在 Android 设备/模拟器执行；iOS 项在可用外部环境执行并记录设备与结果。

- [ ] 冷启动在 2 秒内进入首页，无白屏或未捕获错误；
- [ ] 五项底部导航顺序、文案、选中状态和分支状态保持正确；
- [ ] 空库存可从首页/全部食物进入手动添加；
- [ ] 名称、正数量、单位和两种到期方式校验正确；
- [ ] 新增后出现轻量成功反馈，列表自动刷新且重启后数据保留；
- [ ] 列表长名称、今天到期、临期和已过期样式无溢出；
- [ ] 详情与原列表数据一致，返回后保留列表位置；
- [ ] 扫码命中、未命中、离线、超时、429/5xx 和权限拒绝均可安全回退；
- [ ] 四类通知设置、聚合、点击跳转、时区重排和取消正确；
- [ ] 清除数据取消不执行，确认后食品/缓存/设置/图片/通知清除且默认项恢复；
- [ ] 数据库、网络、相机或通知错误只展示友好信息；
- [ ] 320×568 小屏与 200% 文本缩放下关键操作可访问；
- [ ] Open Food Facts 来源、ODbL、本地存储与联网范围说明可见；
- [ ] `dart format --output=none --set-exit-if-changed .`、`flutter analyze`、`flutter test` 通过；
- [ ] Android 调试 APK 与发布候选构建通过；
- [ ] macOS CI 的 `flutter build ios --no-codesign` 通过；
- [ ] iOS 真机、签名和 TestFlight 结果已记录；无环境时明确标为外部阻塞。
