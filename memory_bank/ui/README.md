# 粮知 App UI 原型

依据参考截图还原的纯 HTML、CSS、JavaScript 移动端原型，包含：

- 粮知首页
- 到期提醒
- 扫码添加
- 全部食物
- 我的（导航占位）
- 牛奶详情

## 实施边界

- 本目录决定颜色、字体、间距、图片、组件形态和整体视觉语言。
- `memory_bank/prd.md`、`memory_bank/architecture.md` 和 `memory_bank/implementation_plan.md` 决定实际功能与数据行为。
- 正式 App 的五项导航固定为：首页、到期提醒、扫码添加、全部食物、我的。
- 原型中的静态食品、关联食谱和仅有按压反馈的按钮仅用于展示，不得作为 V0.1.0 的预置业务数据或已实现功能。
- 正式 App 名称统一为“粮知”；Logo、应用图标和启动页将在实施阶段原创设计。

## 运行

可以直接双击 `index.html`，或在本目录启动静态服务器：

```powershell
python -m http.server 4173
```

随后访问 `http://127.0.0.1:4173/`。

## 可用导航

- 底部导航可进入首页、到期提醒、扫码添加和全部食物；“我的”在静态原型中为视觉占位，正式 App 必须实现。
- 点击首页库存中的“牛奶”或全部食物中的“牛奶”可进入详情。
- 子页面左上角返回按钮可回到上一页。

当前 HTML 原型中的扫码、编辑、删除和数据增减按钮仅保留视觉与按压反馈，不会修改静态数据。
