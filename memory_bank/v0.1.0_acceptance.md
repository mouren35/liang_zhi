## 权限与隐私

Android 只保留：

- `INTERNET`：只读查询 Open Food Facts；
- `ACCESS_NETWORK_STATE`：网络库判断连接状态；
- `CAMERA`：扫描一维商品条形码；
- `POST_NOTIFICATIONS`：Android 13+ 本地提醒；
- `RECEIVE_BOOT_COMPLETED`：恢复待处理本地提醒；
- `VIBRATE`：本地通知提醒；
- AndroidX 动态接收器内部非导出权限：限制应用自身动态接收器访问。

未申请位置、联系人、存储、麦克风、账号或精确闹钟权限。食品库存不上传；远程请求只包含规范化条码和本地化/字段白名单参数。

## 已知限制与外部阻塞

- iOS 无签名编译必须由 macOS CI 执行；当前提交尚未推送，不能把工作流定义等同于实际通过；
- iOS 真机相机、本地通知、签名和 TestFlight 需要外部 Mac、Apple 设备和凭据；
- 正式发布前仍需完成 Open Food Facts API 使用登记和可用代理环境的真实流量复核；
- Open Food Facts 对中国商品覆盖不保证，未命中或网络失败始终回退到保留条码的手动添加；
- Android release 候选使用当前工程签名配置；商店正式签名不在本地测试凭据范围内。

## 冻结条件

只有在最终格式、分析、全量测试、Android debug/release 构建和 Git 工作区提交完成后才能创建 `v0.1.0` 标签。标签后的全新检出验证必须使用标签指向的提交；上述 iOS 外部阻塞不得被改写为已通过。
